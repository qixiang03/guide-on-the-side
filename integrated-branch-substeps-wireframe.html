Part F: Complete Toggle Logic Rules
Quiz Type Branching Give-Up On Max Attempts Next Button Summary Display
Main — Neither OFF OFF Unlimited retries Locked until correct ✅ Correct (N attempts)
Main — Branching ON (max N) OFF (disabled) Sub-Qs injected, main marked wrong permanently Auto-advances to sub-Q after trigger ❌ Wrong (N attempts, branched)
Main — Give-Up OFF (disabled) ON (max N) Answer + explanation revealed, Next unlocked Unlocked after give-up ⚠ Given up (N attempts)
Branch sub-Q — Neither N/A (not available) OFF Unlimited retries Locked until correct   ↳ ✅ Correct (N attempts)
Branch sub-Q — Give-Up N/A (not available) ON (max M) Answer + explanation revealed, Next unlocked Unlocked after give-up   ↳ ⚠ Given up (M attempts)

// NORMAL FLOW (no branching/give-up on any quiz) [Q1] → [Q2] → [Q3] → [Q4] → [Q5] → [Q6] → [Q7] → [Summary] ✓ ✓ ✓ ✓ ✓ ✓ ✓ total: 7 // BRANCHING TRIGGERED (Q3 wrong 3×, 2 sub-Qs) steps[] mutated at runtime: BEFORE: [ Q1, Q2, Q3, Q4, Q5, Q6, Q7 ] // length = 7 AFTER: [ Q1, Q2, Q3*, Q3a, Q3b, Q4, Q5, Q6, Q7 ] // length = 9 ↑ ↑ ↑ perm-wrong injected sub-questions Q3* = main quiz, permanently marked wrong, showing last failed attempt state Q3a, Q3b = new H5P quizzes from librarian branch config, with own tutorial URLs After student answers Q3a correctly → moves to Q3b After student answers Q3b correctly → moves to Q4 Sub-questions stay in the array — they don't collapse. // GIVE-UP TRIGGERED (Q5 wrong 5×) [...Q4] → [Q5⚠] → [Q6] → [Q7] → [Summary] ↑ answer revealed, Next unlocked quiz stays in failed state (not re-attemptable) // NAVIGATION BACK RULES Rule 1: Back goes to any previously visited step (shows preserved state) Rule 2: Forward goes to any step up to the FURTHEST REACHED (not beyond) Rule 3: Correctly answered questions are NOT re-attemptable (frozen ✓) Rule 4: Wrong/given-up questions show their last attempt state (frozen ✗/⚠) Rule 5: Only the CURRENT (furthest unanswered) step accepts quiz input
